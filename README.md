# антитруд.

Независимый проект, переводящий на русский язык ключевые книги и тексты о критике труда, посттрудовом обществе, базовом доходе и свободе от принудительной продуктивности.

Проект ставит под сомнение существующую парадигму наёмного труда и исследует возможные модели будущего, где работа не является центром жизни человека.

## 📚 Содержание

Проект представляет собой структурированную библиотеку переводов, разделённую по тематическим категориям:

- **Библиотека**: Переводы книг и статей о критике труда.
- **Каталог**: Тематические подборки материалов (посттруд, гендер, психология, философия, история, базовый доход и другие).
- **Новости**: Обновления о ходе переводов и публикации новых материалов.
- **Тест на этичность**: Интерактивный опросник для саморефлексии.

## 🛠 Технологии

- [Next.js](https://nextjs.org/) — React-фреймворк для серверного рендеринга и генерации статики.
- [TypeScript](https://www.typescriptlang.org/) — типизация кода.
- [Vercel](https://vercel.com/) — хостинг и автоматическое развёртывание.
