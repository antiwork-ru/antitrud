# антитруд. переводы – Next.js версия

## Структура

- `src/app/page.tsx` – главная
- `src/app/articles/page.tsx` – страница “Статьи”
- `src/components/*` – компоненты (Hero, библиотека, статьи, футер и т.д.)
- `src/data/*` – данные (книги, статьи, цитаты, “слоганы”)

## Локальный запуск

```bash
npm install
npm run dev
```

## Продакшен-сборка

```bash
npm run build
npm run start
```
